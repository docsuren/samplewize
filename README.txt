Samplewize: installable web app

To make the app public, upload all files in this folder to any HTTPS web host, such as GitHub Pages, Netlify or an institutional server. Keep the files together in one folder.

To install: open the address on a phone. In Chrome on Android, choose Install app or Add to Home screen. In Safari on iPhone, tap Share, then Add to Home Screen.

After the first visit the calculators work offline. Calculations run on the device and entered values are not sent anywhere.

Installation requires HTTPS. Opening index.html directly from a file does not enable installation or offline use.
